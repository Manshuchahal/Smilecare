# SmileCare – Dental Care Website

SmileCare is a modern, responsive dental clinic website designed to provide patients with an easy and professional way to explore dental services, learn about the clinic, and get in touch with dental professionals.

### Features

* Dental services and treatments showcase
* Dentist/doctor information
* Appointment and contact section
* Clinic information and location
* Fully responsive design
* Clean and modern healthcare-focused UI
* Fast and user-friendly interface

### Technologies

* HTML
* CSS
* JavaScript
* Responsive Web Design

SmileCare focuses on creating a trustworthy digital experience for dental clinics while making it simple for patients to find information and contact the clinic.
